# Git & GitHub – bases

## Git
Git est un outil qui permet de gérer les versions d’un projet.
Il fonctionne en local sur mon ordinateur.

## GitHub
GitHub est une plateforme en ligne pour stocker et partager des dépôts Git.

## Commandes principales
- git clone : copier un repo en local
- git status : voir l’état du projet
- git add : préparer les fichiers
- git commit : enregistrer un changement
- git push : envoyer sur GitHub
- git pull : récupérer les changements

## Branche
Une branche permet de travailler sans casser le code principal.

## SSH
SSH permet de se connecter à GitHub sans mot de passe.
C’est la méthode utilisée en entreprise.
